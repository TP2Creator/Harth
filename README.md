# HARTH NBL GitHub Pages Website

A neon-purple link-in-bio style website inspired by the supplied reference image.

## 1. Edit your links

Open `index.html` and replace the `https://example.com` URLs with your real:
- Online Store
- Support page
- TikTok
- YouTube
- Telegram
- Instagram
- Discord

## 2. Publish on GitHub Pages

1. Create a GitHub repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will be available at `https://YOURUSERNAME.github.io/`.

No server or backend is required.
